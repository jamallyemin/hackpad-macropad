# hackpad-macropad :3

very kewl 3-key macropad made for hack club hackpad! 

it has a rotary encoder, 0.91" oled screen, rgb led (ws2812b), and a buzzer to make cool noises. powered by seeed studio xiao rp2040.

## stuff used (BOM)
- **MCU:** Seeed Studio XIAO RP2040
- **Switches:** 3x Mechanical MX Switches
- **Encoder:** EC11 Rotary Encoder
- **Display:** 0.91" I2C OLED
- **RGB:** WS2812B / Neopixel LED
- **Audio:** Piezo Buzzer
- **Case:** 3D Printed Top & Bottom
